Research Question

Can GPU-accelerated machine learning detect malicious network flows accurately and efficiently on a dataset containing more than one million records?

Practical Value

A system that flags malicious flows in near real time — with the throughput to keep up with high-volume network traffic — supports faster detection and response than manual or rule-based inspection alone.

About this demo: the notebook's real Random Forest (99.80% accuracy) was trained with a GPU on 1.37M real CIC-IDS2017 rows via RAPIDS cuML — a pipeline that needs a GPU and the full dataset, neither of which fit a free CPU web host. This live demo instead runs a lightweight scikit-learn Random Forest (held-out accuracy: {{ '%.1f'|format(demo_metrics.accuracy * 100) }}%, F1: {{ '%.1f'|format(demo_metrics.f1_score * 100) }}%) trained on synthetic traffic statistically calibrated to match the real correlations and class patterns this project's EDA discovered. It's a genuine, freely-trained classifier for interactive exploration — not a substitute for the full research result. See the notebook and ml_model/train_model.py for the exact methodology.
