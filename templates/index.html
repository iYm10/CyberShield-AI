Problem Statement

Manual traffic inspection doesn't scale

Modern networks generate millions of flows. Denial-of-service attacks, brute-force attempts, bot activity, port scanning, infiltration, and web attacks can all cause service disruption and data loss — and none of it can be caught by hand.

Research Question

Can GPU-accelerated machine learning detect malicious network flows accurately and efficiently on a dataset containing more than one million records?

Practical Value

A system that flags malicious flows in near real time — with the throughput to keep up with high-volume network traffic — supports faster detection and response than manual or rule-based inspection alone.

Dataset

CIC-IDS2017 Network Intrusion Dataset

1.5 million flows loaded from 8 capture files spanning a full working week of labeled benign and attack traffic, cleaned down to 1,373,802 modeling-ready rows across 72 features.

About this demo: the notebook's real Random Forest (99.80% accuracy) was trained with a GPU on 1.37M real CIC-IDS2017 rows via RAPIDS cuML — a pipeline that needs a GPU and the full dataset, neither of which fit a free CPU web host.
